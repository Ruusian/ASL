# Security Policy

## Supported Versions

This repository is a nightly development fork of Ruusian/ASL. Security fixes
are applied to the current `master` branch. Older nightly snapshots are not
guaranteed to receive fixes.

## Reporting a Vulnerability

Please do not publish exploit details in a public issue. Report security
problems privately through the repository owner's GitHub security contact or
request a private maintainer contact in an issue without including sensitive
details.

Include the affected command or file, execution mode, device/Android version,
reproduction steps, and the potential impact. Do not include passwords, SSH
private keys, access tokens, or personal data.
