## Quick Project Summary

ASL is a root-accelerated Linux chroot management system for Android/Termux on ARM64 devices. It provides a bash-based CLI framework (50+ subcommands) for managing Debian chroots, desktop environments, GPU acceleration, and gaming subsystems.

**Key Technologies**: Bash shell scripting, Debian chroot, proot-distro, Termux:X11, PulseAudio

## Key Code Segments

### bin/asl - Main CLI

**Important Functions**:
- `run_in_chroot()` (Lines 48-63): Base64 command encoding with size validation (40KB limit)
- `process_manager()` (Lines 369-403): Process termination with race condition protection (kill -0 checks)
- `show_help()`, `dashboard()`, `overview()`: TUI display functions
- `is_safe_target_pid()`: PID validation for termux/chroot processes

**Dependencies**: Sources core/gpu-profile.sh, calls subscripts in core/, desktop/, gaming/

### core/mount-chroot.sh - Chroot Setup

**Key Code**:
- Lines 6-10: Validation with installation guidance error message
- Lines 78-96: Quoted variable references (`"$DEBIANPATH"`) for security
- Lines 103-110: Mount verification with debugging commands
- Mount operations: /dev, /proc, /sys, /dev/pts, /sdcard, /tmp, /run

### core/stop-chroot.sh - Cleanup

**Key Code**:
- Lines 24-25: Enhanced status messaging
- Lines 78-89: Comprehensive error handler with 4-step troubleshooting
- Process cleanup: SIGTERM then SIGKILL for wine/box64 processes
- Mount cleanup: Reverse order unmounting with lazy force fallback

### desktop/start-desktop.sh - Desktop Lifecycle

**Key Code**:
- Lines 88-105: File descriptor management (explicit FD 3)
- State file: ~/.local/state/asl/desktop/state (persists X11, SESSION, AUDIO pids)

## Testing Procedures

Before pushing changes:

1. **Syntax Check All Files**:
   ```bash
   bash -n bin/asl bin/superkit
   for f in core/*.sh desktop/*.sh gaming/*.sh tools/*.sh; do bash -n "$f"; done
   ```

2. **Run ShellCheck**:
   ```bash
   shellcheck --severity=warning bin/asl core/*.sh desktop/*.sh
   ```

3. **System Diagnostics**:
   ```bash
   bash bin/asl doctor
   ```

4. **Manual Testing** (requires Debian rootfs):
   ```bash
   bash bin/asl start          # Tests mount-chroot.sh fixes
   bash bin/asl ps             # Tests process_manager race condition fix
   bash bin/asl stop           # Tests stop-chroot.sh error handling
   bash bin/asl exec "cmd..."  # Tests command size validation (try oversized cmd)
   ```
